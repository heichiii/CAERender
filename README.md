**表面提取**：
1. 增量优化
2. 重复计算检查
3. 排序对比
4. 排序优化：对全部面排序找边界面，再把边界面三角化并复制成 flat shading 顶点。这会导致两个问题：一是全量排序在大模型上代价不低，二是顶点、法线、索引、映射都被展开，内存量会迅速膨胀。优化方向包括：用哈希计数面出现次数替代全排序，尽量保留共享顶点而不是完全展开，法线生成与字段映射分离缓存，只在网格变化时重建一次。
5. VTK API对比
